Battly Overlay 1.0.0 separates the Worlds interface from account services.

Packages are available for Windows x86/x64, Linux x64/ARM64 and macOS Intel/Apple
Silicon. Linux/Wayland uses a companion panel. Exclusive fullscreen support depends
on the compositor and game; see the README before reporting an invisible HUD.

This component is loaded by a compatible Battly host. It is not a standalone
Minecraft mod or an installer. Native compatibility checks remain necessary; a
successful build is not proof of every fullscreen, DPI or window-manager mode.
