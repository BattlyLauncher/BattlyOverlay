Battly Overlay 1.0.4 updates the Worlds interface and translations to match Battly 3.1. It includes the current room controls, invitations, reporting, scrollbars and emoji rendering.

Packages are available for Windows x86/x64, Linux x64/ARM64 and macOS Intel/Apple Silicon. Windows trackers are signed with Azure before packaging. Accounts, networking, audio and window focus remain managed by the Battly host.
